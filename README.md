# 🛡️ Desafio SOC: Automação de Logs (Parsing)

## 🎯 Sobre o Projeto
Esta é uma aplicação web interativa de arquivo único (HTML, CSS e JS) desenvolvida com foco pedagógico. O objetivo é transformar o aprendizado de processamento de dados em uma experiência imersiva. 

Em vez de um roteiro estático, o aluno assume o papel de um Analista de Cibersegurança que precisa utilizar a lógica de programação para conter um ataque hacker em um servidor educacional sob pressão de tempo, combatendo a fadiga de alertas.

## 🚀 Conceitos Abordados
Embora a interface seja web, a lógica do simulador testa conhecimentos fundamentais de **Python**:
*   Verificação de booleanos com o operador `in`.
*   Extração de dados e *slicing* com o método `.split()`.
*   Injeção de variáveis e formatação de saídas com *f-strings*.

## 🛠️ Como Utilizar
1. Acesse a página do projeto (via GitHub Pages).
2. Clique em **[ INICIAR PROTOCOLO DE DEFESA ]**.
3. Resolva as três fases de análise de logs antes que o tempo (5 minutos) acabe. Erros descontam tempo do cronômetro.
4. Ao final, preencha seu nome no Relatório Oficial e tire um print para validação da atividade prática.
